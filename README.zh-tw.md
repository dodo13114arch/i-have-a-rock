# I Have a Rock

*一款連結 Zotero 與 Obsidian 的外掛。*

[English](README.md) · [繁體中文](README.zh-tw.md)

## 為什麼叫這個名字？

Zotero 的名字源自阿爾巴尼亞語 *zotëroj*，意思是「擁有、掌握」。

而 Obsidian，顧名思義，就是「黑曜石」。

所以，我有了顆石頭。

## 需求

需要 Zotero 10，並在 Zotero 設定裡開啟 Local API。

## 隱私

| | |
|---|---|
| 網路使用 | 只連本機的 Zotero（`127.0.0.1:23119`，Zotero Local API），不連網際網路。 |
| 讀取 vault 以外的檔案 | 讀 Zotero 資料夾的 `storage/`（顯示 PDF）和 `cache/library/`（標注圖片），只讀不寫。 |
