# 使用說明

[English](usage.md) · [繁體中文](usage.zh-tw.md)

## 1. 安裝與設定

### 需求

- Obsidian 1.14.4 以上，僅限桌面版。
- 同一台電腦上的 Zotero 10 桌面版，並開啟 Local API。外掛透過 `127.0.0.1:23119` 與 Zotero 溝通，不會連到網際網路。

### 開啟 Zotero 的 Local API

- 在 Zotero：**設定 → 進階**，勾選 **“Allow other applications on this computer to communicate with Zotero”**（允許這台電腦上的其他程式與 Zotero 溝通；中文介面的文字可能不同）。
- 使用時 Zotero 要保持執行（放在背景，或設成登入時自動開啟）。沒有執行時，面板會顯示「無法連到 Zotero」。

### 安裝外掛

- Obsidian：**設定 → 社群外掛 → 瀏覽**，搜尋 **I Have a Rock**，安裝並啟用。
- 開啟面板：左側功能區的圖示，或指令 **開啟 Zotero 面板**。面板會出現在右側欄。
- 確認連線：**設定 → I Have a Rock → 連線 → 測試連線**。

### 寫入權限

- 讀取不需要權限；寫入才需要：儲存 Zotero 筆記，新增、編輯、刪除標注與評論，更改標注顏色。
- 第一次寫入時，Zotero 會跳出詢問視窗（Obsidian 會顯示「請在剛開啟的 Zotero 視窗中允許寫入。」）。選 **“Always allow”**（一律允許；中文介面的文字可能不同）就不會再問；只允許一次的話，只對那一次寫入有效。
- 取消授權：**設定 → I Have a Rock → 連線 → Zotero 寫入權限 → 取消寫入授權**。下次寫入時 Zotero 會再詢問。

## 2. 基本操作

### 面板

- 開著一份筆記時，面板依閱讀順序列出這份筆記引用的 Zotero 論文，以及每一處引用。
  - 點一下引用：跳到筆記中的位置。雙擊：打開該論文並停在這筆標注。
  - 雙擊論文（或右鍵 → **打開論文**）：進入論文頁面，有 **PDF 標註** 與 **Zotero Notes** 兩個分頁。
- 搜尋：上方的放大鏡（或指令 **搜尋 Zotero**），可搜標題、作者或年份。
- 跟隨連結：游標停在筆記中的 Zotero 連結時，面板會切換到該論文（設定 **跟隨 Zotero 連結**；指令 **切換：跟隨筆記中的 Zotero 連結**）。**釘選** 可固定目前的論文。
- 排序標注：論文頁面上的箭頭按鈕（頁面順序、時間——新到舊或舊到新——或類型）。

### 標注卡片（面板）

- 點一下：選取（若有開著這份 PDF 的 Zotero PDF 分頁，會捲到該處）。↑/↓ 在卡片間移動。
- 拖曳到筆記：插入標注（見下方）。
- 空白鍵：Quick Look。
- 雙擊評論：編輯評論。雙擊其他地方：跳到筆記中的引用。
- 右鍵：**插入筆記**（或 **連結選取文字**）、**預覽**、**跳到筆記中的引用**、**在 Zotero PDF 開啟**、**在 Zotero 開啟**、**編輯評論**、**複製連結**、**刪除標注**。

### 論文標題

- 拖曳到筆記：引用整篇論文，`[標題 (Smith et al., 2025)](zotero://select/…)`。
- 空白鍵：以 Quick Look 預覽第一頁。
- 右鍵：**預覽**、**在 Zotero PDF 開啟**、**在 Zotero 開啟**、**複製 Zotero 連結**、**複製文內引用**、**複製參考文獻**。

### 把標注放進筆記

- **拖曳** 卡片（或 Zotero PDF 頁面上的標注）到筆記。
- **插入筆記**（卡片右鍵選單）：插入到最近使用的筆記游標處，筆記需在編輯模式。
- **連結選取文字**：先在筆記中選取文字，同一個選單項目會把選取文字變成連到這筆標注的連結，文字不變。
- **單筆標注的格式**（設定）：拖曳或插入一筆標注時寫出的樣子，並顯示範例結果。內建格式：
  - **行內 APA 引用**（預設）：`[文字](zotero://…) (Smith & Chen, 2020)`
  - **行內 APA 引用（含頁碼）**：`[文字](zotero://…) (Smith & Chen, 2020, p. 5)`
  - **行內 APA 引用（無連結）**：`文字 (Smith & Chen, 2020)`
  - **連結**：`[文字](zotero://open-pdf/…)`
  - **引用＋出處**：引用區塊，最後一行是 `— Smith and Chen, 2020, p. 5`
  - 結果只有一行時插在游標處；多行、引用、清單、標題或圖片則自成一段。
- 自訂格式（格式選單旁的按鈕）：
  - **新增格式**（＋）、**複製格式**（內建格式也能複製）、**重新命名格式**、**刪除格式**（會先確認）。新增或複製的格式會直接被選用。
  - 選擇自訂格式即可編輯範本，預覽會跟著更新，邊打邊存。
  - 編輯區下方的 **使用說明** 可展開簡短說明與變數清單（見下方「範本」）。內建格式無法修改，複製一份就能自訂。
  - 每個自訂格式都是範本資料夾裡的檔案，整理成筆記時也能選。
- 圖片標注：圖片會複製到 Vault（設定 **圖片標註資料夾**，或 Obsidian 的附件資料夾），以帶連結的圖片插入。

### 整理成筆記

- 論文頁面上的筆記本按鈕：把這篇論文的標注整理成一份新筆記。
- 可選類型、顏色、標注時間（全部、今天、最近 7 天、上次整理之後）、排序、格式（範本）、是否保留 Zotero 連結，以及筆記名稱。
- 存放位置：**設定 → 整理成筆記 → 資料夾**。

### 範本

- 資料夾：`<vault>/.obsidian/plugins/i-have-a-rock/templates`（若改過設定資料夾名稱，則在該資料夾下）。可從 **設定 → 整理成筆記 → 範本 → 開啟資料夾** 打開。
- 每個 `.md` 檔是一種格式，整理時與 **單筆標注的格式** 都可以選；在 Obsidian 外修改檔案也會生效。資料夾一開始有兩份；內建格式也會一起列出（整理成筆記時，同名的檔案會取代內建格式）。
- 變數：
  - `{{text}}` 標注文字（圖片標注是圖片），連回 Zotero
  - `{{text_plain}}` 標注文字，不加連結
  - `{{comment}}` `{{page}}` `{{color}}` `{{type}}` `{{date}}` `{{time}}`
  - `{{citation}}` `Smith et al., 2025` · `{{citation_page}}` `Smith et al., 2025, p. 5`
  - `{{apa}}` `(Smith et al., 2025)` · `{{apa_page}}` `(Smith et al., 2025, p. 5)`；沒有頁碼時與 `{{apa}}` 相同
  - `{{authors}}` `Smith et al.` · `{{first_author}}` `Smith` · `{{year}}` `2025`；不知道時是空的（`{{apa}}` 則寫 `n.d.`）
  - 自訂樣式，例如 `{{text}} — {{first_author}} ({{year}})` 會寫出 `[文字](zotero://…) — Smith (2025)`。
- 某一行的變數都是空的，整行會拿掉。`%% … %%` 註解不會出現在筆記裡。

### 預覽

- **Quick Look**：在卡片或論文標題上按空白鍵、右鍵選單的 **預覽**，或連結預覽卡（見下方）。
  - ↑/↓ 上一筆／下一筆 · Enter 在 Zotero PDF 開啟 · 空白鍵、Esc 或點外面關閉。
  - ⌘/Ctrl + `=` / `-` 縮放，⌘/Ctrl + `0` 符合寬度；觸控板捏合也可縮放。
  - **自訂預覽視窗大小與位置**（設定 → Quick Look）：可調整大小與移動，下次在同樣位置打開。
- **連結預覽卡**：中間標著「Quick Look」的小玻璃卡片：標注連結顯示標注在頁面上的位置，並以標注顏色標出；連到論文的連結（例如從論文標題拖進來的）顯示第一頁（或連結指定那一頁）的上半部。點一下打開 Quick Look，那裡也有 **在 Zotero 開啟**。沒有 PDF 的論文不顯示預覽卡。
  - 把文字游標放到 Zotero 連結上時出現：點一下連結會立刻出現，用鍵盤移過去則稍等一下。卡片在連結上方（上方放不下時改在下方），對齊游標，游標在連結裡移動時（用鍵盤或滑鼠）跟著移動，游標離開連結時消失。外掛自己移動游標時（例如從面板跳到筆記裡的引用、插入標注）不會出現。
  - 閱讀模式下，點 Zotero 連結會在連結旁、點的位置顯示預覽卡；點其他地方即消失。
  - 打字、捲動、調整視窗大小、切換視窗或按 Esc 時也會消失；調整窗格大小時則跟著移動。
  - 設定 **點擊 Zotero 連結時**：**顯示預覽卡**（預設）讓一般點擊連到標注或論文的連結時不會跳到 Zotero；在即時預覽中會把游標放進連結，可以直接編輯，並顯示預覽卡。**不做任何事** 同樣讓點擊不會跳到 Zotero（即時預覽中游標會放進連結；閱讀模式下不做任何事），也完全不顯示預覽卡。**跳到 Zotero** 則和以前一樣開啟 Zotero，也完全不顯示預覽卡。群組文獻庫的連結，以及按著修飾鍵的點擊，維持原樣。
- **Zotero PDF 分頁**：**在 Zotero PDF 開啟**（右鍵選單，或在 Quick Look 按 Enter）會在筆記旁打開 PDF。

### 在 Zotero PDF 標注

- 設定 **在 Zotero PDF 建立標注**：
  - **先選取，再選顏色**：選取文字後選顏色（螢光筆或底線）。從頁面空白處拖曳，或按住 ⌥/Alt 拖曳，可框選範圍（圖片標注）。
  - **先選工具，再選取**：先在頁面上方選螢光筆、底線或框選工具，再選取。
  - **兩者都要**，或 **關閉（只能閱讀）**。
- 點頁面上的標注：跳到它的卡片。雙擊：在面板編輯評論。也可以拖曳到筆記。
- 右鍵標注：改顏色、**複製文字**、**在 Zotero 開啟**、**刪除標注**。
- 新標注會立刻寫入 Zotero（需要寫入權限）。**頁面顏色** 與 Zotero 閱讀器的主題相同。

### 編輯評論

- 雙擊卡片上的評論，或右鍵 → **編輯評論**。
- ⌘/Ctrl+Enter 或 **儲存到 Zotero** 儲存；Esc 或 **取消** 放棄。
- 若編輯期間 Zotero 裡的評論也被修改，可選 **保留 Zotero 版本** 或 **保留我的草稿**。
- 需要寫入權限。

### Zotero Notes

- 論文的 **Zotero Notes** 分頁：閱讀、**編輯**、**儲存到 Zotero**。未儲存的修改會保留為草稿，重新啟動後也還在。有衝突時可 **比較版本**。含有無法安全編輯內容的筆記為唯讀。

### 匯出一份筆記的參考文獻

- 面板顯示筆記時：上方的書本按鈕（**複製這份筆記引用的所有文獻的參考文獻**），或在筆記標題上按右鍵 → **複製這份筆記的參考文獻**。
- 格式與語言：**設定 → 引用 → 引用格式**（預設 APA 7th）與 **引用語言**。由 Zotero 產生。
- 同時複製純文字與帶格式的 HTML：貼到筆記會變成 Markdown，保留斜體。

## 3. 疑難排解

- **「Zotero 未執行」／「無法連到 Zotero」**：啟動 Zotero，再按 **重試** 或執行指令 **重新連線 Zotero**。
- **「Local API 未啟用」**：在 Zotero 開啟（見上方）。
- **儲存失敗，或「Zotero 拒絕了寫入權限」**：再寫入一次，在 Zotero 的詢問視窗選 **“Always allow”**；或在設定中 **取消寫入授權** 後再試。
- **圖片標注沒有預覽**：在 Zotero 開啟這筆標注一次，讓 Zotero 產生圖片；並確認設定中的 **Zotero 資料目錄**。
